# XQB-BPBox

XQB-BPBox 是一款为《星穹杯》开发，面向《崩坏：星穹铁道》相关 BP 场景的桌面工具，使用 Electron、React 和 TypeScript 开发。项目通过本地文件管理角色、光锥、BP 流程、展示设置、音视频配置和 BP 结果，可用于非商业赛事、社区活动、学习研究及个人内容制作。

> **授权提示：** 本项目源代码公开供个人学习、研究及非商业用途使用。商业使用及商业赛事使用前，必须联系作者并取得授权。操作教程中包含或由使用者自行配置的第三方游戏图片、角色素材、视频、音频、字体等，不属于本项目程序代码的授权范围。

## 主要功能

- 管理角色与光锥资料，以及对应的图片、语音、音效和视频路径。
- 创建、导入、读取和保存 BP 流程，配置 Pick、Ban、保护、租借及流程事件。
- 配置展示页背景、槽位布局、页面变化、唱名视频和 Pick/Ban 等特效。
- 使用独立预览窗口检查展示效果，并在 BP 操作时同步独立展示窗口。
- 执行并记录 BP 流程，将结果保存到本地，供后续读取与复盘。
- 使用配音轴将音频、BP 流程和已保存结果对齐，按时间点驱动展示页推进。
- 通过 `XQB-BPbox/assets/`、`XQB-BPbox/config/` 和 `XQB-BPbox/results/` 目录管理素材、配置和结果。

## 下载与安装

普通用户无需配置开发环境，可前往 [GitHub Releases](https://github.com/1150664753/XQB-BPbox/releases) 选择所需版本并下载安装包。Windows 用户可下载名称类似 `XQB-BPBox-<版本号>-setup.exe` 的安装程序，按安装向导完成安装后启动软件。

如需了解素材准备、角色与光锥导入、BP 流程配置、展示页设置和配音轴使用，请阅读 [操作指南](./操作指南.md)。

## 基本使用流程

1. 按操作指南准备角色、光锥及所需音视频素材。
2. 在“角色管理”和“光锥管理”中导入或维护数据。
3. 在“BP流程配置”中使用默认流程或创建自定义流程并保存。
4. 在“展示页设置”中调整背景、槽位、页面变化和特效，并打开预览页检查效果。
5. 进入“开始BP”，读取流程、打开展示页，按当前步骤完成选择并保存结果。
6. 如需配音联动，在“配音轴”中导入音频，关联流程与 BP 结果并设置推进时间点。

详细字段、素材命名和常见问题以现有[操作指南](./操作指南.md)为准，README 不重复展开完整教程。

本项目采用源码公开（Source Available）的发布方式。你可以在遵守 [LICENSE](./LICENSE) 的前提下，为个人学习、研究和非商业用途查看、运行和修改源代码；这不表示项目采用 OSI 认可的开源许可证。

项目主要代码位于：

```text
XQB-BPbox/src/main/          Electron 主进程
XQB-BPbox/src/preload/       预加载脚本与渲染进程桥接
XQB-BPbox/src/renderer/src/  React 界面、展示页与预览页
XQB-BPbox/src/shared/        主进程与渲染进程共用类型和逻辑
```

安装依赖并启动开发环境：

```bash
cd XQB-BPbox
npm install
npm run dev
```

常用检查与构建命令：

```bash
npm run typecheck
npm run lint
npm run build:win
```

macOS 和 Linux 构建脚本也已在 `XQB-BPbox/package.json` 中提供。自行构建、分发或使用时，仍须遵守本项目授权条件，并自行确认第三方依赖和素材的许可要求。
