# XQB-BPBox 操作指南

本文档用于说明 XQB-BPBox 的日常使用流程。截图位置已预留，后续可直接补充图片。

## 1. 软件启动

1. 双击启动 `XQB-BPBox`。
2. 启动后默认进入控制台页面。
3. 左侧图标栏用于切换主要功能：
   - 角色管理
   - 光锥管理
   - BP流程配置
   - 展示页设置
   - 开始BP
   - 配音轴

![控制台首页截图](./docs/images/01-console-home.png)

## 2. 素材目录

软件读取项目目录下的 `assets`、`config`、`results` 文件夹。

常用素材路径如下：

```text
assets/
  audios/
    ban/
      ban_00001.wav
    pick/
      pick_00001.wav
    pick_sound/
      pick_sound_00001.wav
  characters/
    big/
      pick_00001.png
    small/
      ban_00001.png
    left/
      left_00001.png
    right/
      right_00001.png
  videos/
    chant/
      chant_00001.png
    PV/
      PV_00001.png
```

说明：

- `ban_编号.wav`：角色 Ban 语音。
- `pick_编号.wav`：角色 Pick 语音。
- `pick_sound_编号.wav`：角色 Pick 音效，会在 Pick 该角色时与 Pick 选定音效、角色 Pick 语音一起播放。
- 编号建议统一使用 5 位数字，例如 `00001`。

![素材目录截图](./docs/images/02-assets-folder.png)

## 3. 角色管理

进入左侧“角色管理”页面。

### 3.1 单个导入角色

1. 填写角色编号、英文名称、中文名称、稀有度、属性、命途。
2. 选择角色素材：
   - 左头
   - 右头
   - 唱名视频
   - PV
   - 头像小图
   - 全身
   - Ban语音
   - Pick语音
   - Pick音效
3. 如角色 PV 需要从中间开始播放，填写“PV开始时间”。
4. 点击“导入角色”。

![角色导入截图](./docs/images/03-character-import.png)

### 3.2 批量导入角色

1. 在“编号”中填写角色编号，例如 `00001`。
2. 填写角色名称、属性、命途、稀有度。
3. 点击单行“批量导入”，或点击“批量导入全部”。
4. 软件会按编号自动匹配素材路径。

批量导入会自动匹配：

```text
assets/audios/ban/ban_编号.wav
assets/audios/pick/pick_编号.wav
assets/audios/pick_sound/pick_sound_编号.wav
assets/characters/big/pick_编号.png
assets/characters/small/ban_编号.png
assets/characters/right/right_编号.png
assets/characters/left/left_编号.png
assets/videos/chant/chant_编号.png
assets/videos/PV/PV_编号.png
```

![角色批量导入截图](./docs/images/04-character-bulk-import.png)

## 4. 光锥管理

进入左侧“光锥管理”页面。

1. 填写光锥名称、命途、稀有度。
2. 选择光锥小图和大图。
3. 点击“导入光锥”。
4. 已导入光锥可编辑、复制或删除。

![光锥管理截图](./docs/images/05-lightcone.png)

## 5. BP流程配置

进入左侧“BP流程配置”页面。

### 5.1 创建流程

1. 点击“使用默认流程”，或手动添加流程步骤。
2. 设置每一步的：
   - 队伍
   - 动作
   - 目标类型
   - 事件触发
   - 页面变化
3. 点击“保存当前流程”。

流程文件会保存在：

```text
config/bp/
```

![BP流程配置截图](./docs/images/06-bp-flow.png)

### 5.2 读取流程

1. 在左侧流程列表中选择流程。
2. 点击“读取左侧选中流程”。
3. 当前流程会应用到 BP 和展示页设置中。

## 6. 展示页设置

进入左侧“展示页设置”页面。

展示页设置分为：

- 基础设置
- 变化设置
- 特效设置

### 6.1 基础设置

用于设置展示页背景、背景图层、唱名视频槽位、BP 框位置等内容。

![展示页基础设置截图](./docs/images/07-display-base.png)

### 6.2 变化设置

用于配置页面变化事件。

常见用途：

- 背景图出现或消失。
- 背景图飞入或飞出。
- 唱名视频区域大小变化。
- 延迟若干次点击后再执行变化。

配置完成后，在 BP 流程步骤的“事件触发”中填写对应事件名即可触发。

![展示页变化设置截图](./docs/images/08-display-changes.png)

### 6.3 特效设置

用于配置 Pick、Ban、保护、租借等槽位特效。

可配置内容包括：

- 待选中特效视频
- 选定特效视频
- 选定音效
- 特效位置与缩放
- 触发事件

![展示页特效设置截图](./docs/images/09-display-effects.png)

### 6.4 打开预览页

点击“打开预览页面”后，会打开独立预览窗口。预览页用于检查展示页布局和效果。

![预览页截图](./docs/images/10-preview-window.png)

### 6.5 保存展示设置

配置完成后点击“保存展示设置”。

展示页配置文件保存在：

```text
config/display/
```

## 7. 开始BP

进入左侧“开始BP”页面。

### 7.1 打开展示页

1. 选择 BP 流程。
2. 点击“读取流程”。
3. 点击“打开展示页”。
4. 正式展示页会以独立窗口打开。

![正式展示页截图](./docs/images/11-display-window.png)

### 7.2 执行BP

1. 按当前步骤选择角色或光锥。
2. 点击确认后，该操作会同步到展示页。
3. Pick 角色时会播放：
   - 展示页 Pick 选定音效
   - 角色 Pick 语音
   - 角色 Pick 音效
4. Ban 角色时会播放：
   - 展示页 Ban 选定音效
   - 角色 Ban 语音
5. 流程完成后，可保存 BP 结果。

![开始BP截图](./docs/images/12-start-bp.png)

### 7.3 保存和读取BP结果

BP 结果保存在：

```text
results/bp/
```

保存后的结果可在左侧“已保存 BP 结果列表”中读取，用于复盘或配音轴制作。

## 8. 配音轴

进入左侧“配音轴”页面。

配音轴用于把一段配音音频和已保存的 BP 结果对齐，并驱动展示页自动推进。

### 8.1 创建配音轴

1. 在左侧配音轴列表中新建配音轴。
2. 导入音频。
3. 选择 BP 流程。
4. 选择 BP 结果。
5. 根据音频时间点插入 BP 点击。
6. 点击“保存”。

配音轴配置保存在：

```text
config/audio/
```

![配音轴编辑截图](./docs/images/13-voice-timeline.png)

### 8.2 打开配音轴联动展示页

1. 确认已导入音频。
2. 确认已选择 BP 流程和 BP 结果。
3. 确认已插入点击点。
4. 点击“打开展示页”。

打开独立配音轴展示页后，预览展示页会自动静音，避免两个窗口同时发声。

![配音轴展示页截图](./docs/images/14-voice-display.png)

## 9. 打包安装包

在项目目录执行：

```bash
cd c:\project\XQB-BP\XQB-BPbox
npm run build:win
```

打包产物位于：

```text
dist/
```

Windows 安装包支持自定义安装目录。

## 10. 常见问题

### 10.1 素材显示缺失

检查素材路径是否存在，尤其是批量导入时的编号是否一致。

例如编号为 `00001` 时，Pick 音效应为：

```text
assets/audios/pick_sound/pick_sound_00001.wav
```

### 10.2 展示页没有声音

检查：

1. 展示页是否已经打开。
2. 对应角色是否配置了语音或音效。
3. 展示页设置中是否配置了 Pick/Ban 选定音效。
4. 系统音量和应用音量是否正常。

### 10.3 配音轴展示和预览页同时发声

新版逻辑会在打开独立配音轴展示页时自动静音预览页。若仍有声音，请关闭旧展示窗口后重新打开。

### 10.4 修改版本号

在项目目录执行：

```bash
npm version 1.0.1 --no-git-tag-version
```

然后重新打包。
